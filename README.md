## ✨프로젝트 제작 이유
이 프로젝트는 제가 처음으로 제작한 개인 작업입니다. 당시에는 HTML, CSS, JavaScript 정도만 다룰 수 있는 학생이었지만,  
머릿속으로만 구상했던 디자인과 애니메이션을 직접 구현해보고 싶어 시작했습니다.  
주제로는 재미있고 창의적인 방법으로 디자인과 애니메이션을 담을 수 있는 **쇼핑 Wishlist 페이지**를 선택했으며,  
상상력과 창의성을 담아낸 애정 어린 작품입니다.

---

## ⭐️프로젝트 핵심 기능
- **독특한 애니메이션**  
  각 페이지 테마에 맞춘 CSS/JS 기반의 진입·호버 애니메이션  
- **인터랙티브 UX**  
  버튼·링크에 호버 시 시각적 피드백 부여  
- **쇼핑 위시리스트 구성**  
  사용자가 제품을 클릭해 위시리스트에 추가/제거 가능  

---

## 🔥 사용 스택 & 이유
- **HTML & CSS**  
  - 페이지 구조와 스타일링 담당  
  - CSS 애니메이션으로 시각 효과 구현  
- **JavaScript**  
  - DOM 조작을 통한 애니메이션 제어 및 사용자 상호작용 처리
